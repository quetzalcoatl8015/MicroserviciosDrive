# Interfaz de Drive por equipos

Aplicación React conectada a las rutas en español de la API incluida.

- Desarrollo: `npm ci` y `npm run dev`.
- Compilación: `npm run build`.
- Revisión: `npm run lint`.

Requiere Node 24. En desarrollo Vite reenvía `/api` a `http://localhost:5239`; en Docker lo hace Nginx. La URL puede personalizarse con `VITE_API_URL`.

Consulta `../README.md` para arrancar el sistema completo, conocer los roles y actualizar una instalación existente.
